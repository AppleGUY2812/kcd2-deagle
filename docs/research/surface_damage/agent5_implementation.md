# Agent 5: CryEngine implementation notes (CE5 public source, mirror ValtoGameEngines/CryEngine @release; KCD2 fork may differ)
Sources read (raw.githubusercontent.com/ValtoGameEngines/CryEngine/release/...): CryCommon/Cry3DEngine/I3DEngine.h, CryEngineDecalInfo.h, Cry3DEngine/{DecalManager,3dEngine,terrain_damage,TerrainModifications,cvars}.cpp, 3dEngineLoad.cpp, CryPhysics/physinterface.h, CryCommon/CryParticleSystem/IParticles.h, Engine/Shaders/HWScripts/CryFX/{Illum.cfx,IllumValidations.cfi,CommonZPass.cfi,FXSamplerDefs.cfi}, Game ActionGame.cpp/IGameRulesSystem.h.

## Key facts
- Height slot: heightTex register(t6)=TM_Height ("Heightmap" slot), file suffix _displ, height in ALPHA of _displ, preset DisplacementMap (A8). Blend layer 2 uses Height2Tex (TM_SubSurface). Bump (normal) still required.
- Illum params: ObmDisplacement (0..0.025, def .004), PomDisplacement (0..0.05, def .025), SilPomDisplacement, SilPomNumSteps (4..512, def 256), SilPomStepSizeViewDep, HeightBias (0..1, def 1), SelfShadowStrength.
- IllumValidations: %DECAL undefines %SILHOUETTE_PARALLAX_OCCLUSION_MAPPING (SilPOM impossible on decals); plain POM (and OBM) stay allowed on decals. Decal pass: ZWrite off, ZFunc LEqual.
- CommonZPass: POM only offsets baseTC.xy (ParallaxOcclusionMap(uv,lod,viewTS,15 steps,disp,bias,...)); no depth write for POM (only SilPOM writes fDepth) => a POM hole is a texture-space illusion, silhouette stays flat.
- CryEngineDecalInfo fields: ownerInfo(SDecalOwnerInfo: pRenderNode,pDecalReceivers,nMatID), vPos, vNormal, fSize, fLifeTime, fAngle, pIStatObj(unused/asserts), vHitDirection, fGrowTime, fGrowTimeAlpha, nGroupId, bSkipOverlappingTest, bAssemble, bForceEdge, bForceSingleOwner, bDeferred, sortPrio(default 255), szMaterialName[_MAX_PATH], preventDecalOnGround, pExplicitRightUpFront(Matrix33*). No depth field; depth comes from e_DecalsDeferredDynamicDepthScale (const cvar).
- I3DEngine: virtual void CreateDecal(const CryEngineDecalInfo&); virtual void OnExplosion(Vec3 vPos,float fRadius,bool bDeformTerrain=true); SetTerrainSurfaceType(x,y,type 0-6, 7=hole); ApplyForceToEnvironment(pos,radius,force); AddWaterRipple(pos,scale,strength).
- OnExplosion impl: needs pos inside terrain; returns if terrain holes nearby; RemoveObjectsInArea must delete everything (non-breakable vegetation/objects block deformation); deform only if bDeformTerrain && e_TerrainDeformations && -0.1<height-above-ground<radius && radius>0.125; MakeCrater -> CTerrainModifications::PushModification; then DeleteDecalsInRange(box) (existing decals in blast are removed). OnExplosion itself spawns NO crater decal/particles.
- Crater math: depth = (1 - dist3D/radius), summed with existing mods, clamped 0..TERRAIN_DEFORMATION_MAX_DEPTH=3.0 m, only above ocean+0.25, writes heightmap Z at heightmap unit grid (so radius must be several units wide), then ReleaseHeightMapGeometry on touched sectors + ResetHeightMapCache. Terrain texture (colour) is NOT touched -> need a crater decal.
- e_TerrainDeformations is DefineConstIntCVar(…, 0, VF_CHEAT) => compile-time constant 0 in release builds (in CE5 source). In KCD2 the cvar still exists as per user, but may be const-folded; must verify in Ghidra whether the check reads a variable.
- Decal cvars: e_Decals(1), e_DecalsForceDeferred(0), e_DecalsDeferredStatic(1), e_DecalsDeferredDynamic(1: gameplay decals deferred), e_DecalsAllowGameDecals(1), e_DecalsMaxTrisInObject 8000, e_DecalsRange, e_DecalsLifeTimeScale 1.0, e_DecalsNeighborMaxLifeTime 4 (new decal near older forces old ones to fade in 4 s if fSize>1), e_DecalsOverlapping 0 (blocks new decal if near existing unless bSkipOverlappingTest), e_DecalsMaxUpdatesPerFrame 4, e_DecalsSpawnDistRatio 4. Const (not settable in release): DeferredDynamicMinSize, DeferredDynamicDepthScale, HitCache, Merge, MaxValidFrames. No e_DecalsMaxCount cvar in this source.
- DecalManager: non-deferred decals wrap geometry (terrain-ground type when fSize>2*minSize and near ground; simple quad otherwise); deferred => projected box, "SimpleQuad", pos nudged 0.001 along normal. Spawn returns false if terrain hole at location.
- pe_explosion fields: epicenter, epicenterImp, rmin, rmax, r, impulsivePressureAtR, nOccRes, nGrow, rminOcc, holeSize, explDir, iholeType (<0 disables breakage), forceDeformEntities, outputs pAffectedEnts/pAffectedEntsExposure/nAffectedEnts. IPhysicalWorld::SimulateExplosion(pe_explosion*, pSkipEnts=0, nSkipEnts=0, iTypes=ent_rigid|ent_sleeping_rigid|ent_living|ent_independent, iCaller). Helper overload takes (epicenter,epicenterImp,rmin,rmax,r,impulsivePressureAtR,nOccRes,nGrow,rminOcc,...).
- ExplosionInfo (IGameRulesSystem.h): shooterId, weaponId, projectileId, damage, pos, dir, minRadius, radius, soundRadius, minPhysRadius, physRadius, angle, pressure, hole_size, pParticleEffect, effect_name, effect_class, effect_scale, type, impact, impact_normal, ... (Crysis-era game layer; KCD2 game layer differs.)
- Particles: IParticleManager::FindEffect(cstr name,cstr src="",bool load=true); CreateEmitter(const ParticleLoc&, const ParticleParams&, const SpawnParams*). SpawnParams: fCountScale,fSizeScale,fSpeedScale,fTimeScale,bIgnoreTerrainLayerBlend,... In CE5.x emitters are spawned via IParticleEffect::Spawn(ParticleLoc, SpawnParams*) (INFERRED).
